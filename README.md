# slahasher

A Rust library providing hashing functions.

## Features

- SHA-256
- Keccak-256
- Keccak-384
- Keccak-512
- RIPEMD-160
- Base encoding support via base_xx

## Installation

Add this to your `Cargo.toml`:

```toml
[dependencies]
slahasher = "0.3.13"
```

## Usage

Documentation is available at [docs.rs/slahasher](https://docs.rs/slahasher)
